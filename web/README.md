# Wandlampe web controller

React + TypeScript + Vite editor for the lamp firmware in `../firmware`.

```sh
npm ci
npm run dev
npm run build
npm run lint
```

See the [repository README](../README.md) for setup, [Vercel deployment settings](../README.md#web-deployment-vercel) for the root directory and production branch, and the [MQTT protocol](../docs/mqtt.md) for mode payloads and device behavior.
